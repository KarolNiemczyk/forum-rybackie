# 🎣 Fishing Store – Full-Stack E-Commerce App

A full-stack web application for an online fishing store with user accounts, product catalog, and shopping cart functionality.

## ✅ Tech Stack
| Layer | Technology |
|-------|------------|
| Frontend | **Next.js**, Tailwind CSS |
| Backend | **Flask (Python)** – REST API |
| Database | **MongoDB** |
| Auth | Custom login system |

---

## 🚀 Features
✔ User registration and login  
✔ Browse products (rods, reels, lures, etc.)  
✔ Add items to cart and modify orders  
✔ Responsive UI (mobile & desktop)  
✔ Separate backend API and Next.js frontend
